# 二、最推荐的实现顺序

## 第 1 步：先把几何底座渲染器补出来

这是后面很多模块的前置依赖。

### 目标

给任意插值位姿输出：

* coarse RGB
* depth
* normal
* alpha / visibility

### 最简单实现路径

不要一开始就写复杂 differentiable renderer。
先做一个 **point / gaussian splat renderer** 就够了。

### 输入

* Part 2 的 point cloud 或 Gaussian
* camera intrinsics / extrinsics

### 输出

* `rgb_coarse`
* `depth`
* `normal`
* `alpha`
* `valid_mask`

### 推荐实现策略

#### 方案 A：如果你有 Gaussian model

直接复用 3DGS 的 renderer，导出：

* RGB
* depth
* alpha
  normal 可以从高斯协方差主方向近似，或者先不做精确 normal。

#### 方案 B：如果你只有 point cloud

做一个最小 z-buffer point splatting：

* 点投影到图像平面
* 按深度排序 / z-buffer
* 颜色 splat 到邻域
* alpha = 是否有点覆盖
* normal 先从点云法向或局部 PCA 估计

### 伪代码

```python
class CoarseGeometryRenderer:
    def __init__(self, points, colors, normals=None, radius=1.5):
        self.points = points      # [N,3]
        self.colors = colors      # [N,3]
        self.normals = normals    # [N,3] optional
        self.radius = radius

    def render(self, K, T_wc, H, W):
        # world -> camera
        pts_cam = transform(self.points, T_wc)              # [N,3]
        valid = pts_cam[:, 2] > 1e-3

        uv = project(K, pts_cam[valid])                     # [M,2]
        z  = pts_cam[valid, 2]

        rgb   = zeros(H, W, 3)
        depth = inf(H, W)
        alpha = zeros(H, W)
        normal= zeros(H, W, 3)

        for i in sort_by_depth(z):
            u, v = uv[i]
            splat_to_neighbors(
                rgb, depth, alpha, normal,
                u, v, z[i],
                color=self.colors[valid][i],
                normal=self.normals[valid][i] if self.normals is not None else None,
                radius=self.radius
            )

        valid_mask = alpha > 0
        return rgb, depth, normal, alpha, valid_mask
```

### 为什么它是 P0

因为后面这些都依赖它：

* `C_vis`
* `C_reproj`
* pose refinement
* 帧筛选
* DynamiCrafter 几何对齐 reranking

## 第 2 步：先做真正的 `C_vis`

你现在的 `valid_map` 只是边界裁剪，不是真正几何可见性。

### 目标

把 OVIE 的“valid region”思想落地成你的像素级几何 mask。OVIE 的关键就是：pseudo-target 监督只作用在 valid regions，而且 perceptual loss 也只在 valid regions 上算。

### 最小可行设计

[
C_{vis} = \mathbf{1}[\alpha > \tau_\alpha] \cdot \mathbf{1}[z < z_{\max}] \cdot \mathbf{1}[\text{not boundary}]
]

如果你有 normal，再加：
[
\mathbf{1}[n \cdot v > \tau_n]
]

### 具体实现

* `alpha > tau`：有几何覆盖
* `depth finite`：不是 hole
* `occlusion boundary`：对 depth 做 Sobel，边界附近降权
* `backface`：若有 normal，用视线方向和 normal 点积过滤
* `out-of-frame`：天然由投影过滤

### 伪代码

```python
def build_c_vis(depth, alpha, normal=None, view_dir=None):
    valid = (alpha > 0.05) & isfinite(depth)

    # occlusion boundary suppression
    depth_grad = sobel(depth)
    boundary = depth_grad > percentile(depth_grad[valid], 90)
    valid = valid & (~dilate(boundary, k=3))

    if normal is not None and view_dir is not None:
        facing = (normal * view_dir).sum(-1) < -0.1
        valid = valid & facing

    c_vis = valid.float()
    return c_vis
```

### 为什么它比 `border_mask` 更重要

因为这才是真正决定“哪里能学”的第一层。
`border_mask` 只能防边缘噪声，不能处理：

* 遮挡切换
* hole
* 背面
* 几何不存在区域

---

## 第 3 步：补 pose refinement

你现在直接把插值 pose 当最终 pose，这是风险很大的。

### 目标

对每个 pseudo-view：

* 先用插值 pose 初始化
* 再用图像与几何对齐做 refinement
* 得到更可信的 pseudo pose

### 最简单实现路径

先做 **2-stage refinement**：

#### Stage A：feature matching + PnP

* 用 coarse render 得到 target pose 下的 depth
* 从 pseudo-view 和 coarse RGB 之间做特征匹配
* 用 coarse depth 把 coarse RGB 上的 2D 点 lifting 成 3D
* 用 `solvePnPRansac` 求 refined pose

#### Stage B：photometric 微调

* 以 PnP 结果为初值
* 在 SE3 上优化 `L1(rendered_coarse, pseudo)` 或 SSIM
* 只做少量迭代

### 伪代码

```python
def refine_pose_with_pnp(pseudo_img, coarse_rgb, coarse_depth, K, init_pose):
    kp1, des1 = extract_features(pseudo_img)
    kp2, des2 = extract_features(coarse_rgb)
    matches = match_features(des1, des2)

    pts2d = []
    pts3d = []
    for m in matches:
        u2, v2 = kp2[m.trainIdx]
        z = coarse_depth[v2, u2]
        if not isfinite(z): 
            continue
        X = backproject(K, u2, v2, z)
        pts3d.append(X)
        pts2d.append(kp1[m.queryIdx])

    if len(pts3d) < 20:
        return init_pose, False

    pose = solve_pnp_ransac(pts3d, pts2d, K, init_pose)
    pose = photometric_refine(pose, pseudo_img, renderer)
    return pose, True
```

### 为什么这是 P0

因为：

* 你后面的 `C_reproj`
* 帧筛选
* consistency
  都默认 pseudo-view 的 pose 至少大致对得上

如果 pose 本身漂，后面所有 consistency 都会误判。

---

## 第 4 步：补基于 reprojection / coarse render 的帧筛选

这一步比 `C_feat` 更该先做，因为简单、收益大。

### 目标

先在 **帧级** 做一次粗筛：

* 丢掉最差的 pseudo-views
* 避免坏帧直接污染训练

### 最小筛选分数

给每个 pseudo-view 一个 score：

[
S_{frame} = w_1 \cdot \text{L1}(I_{pseudo}, I_{coarse})

* w_2 \cdot \text{LPIPS}(I_{pseudo}, I_{coarse})
* w_3 \cdot \text{ReprojErr}
  ]

### 简化版建议

第一版甚至可以先不用 LPIPS，只用：

* coarse render L1
* reprojection error
* forward-backward flow consistency

### 伪代码

```python
def score_pseudo_frame(pseudo_img, coarse_rgb, reproj_err, flow_err):
    l1 = mean(abs(pseudo_img - coarse_rgb))
    score = 0.4 * normalize(l1) + 0.4 * normalize(reproj_err) + 0.2 * normalize(flow_err)
    return score
```

### 使用方式

* 每个 clip 保留 top-k
* 或者去掉最差 20% 帧
* 剩下的再进入 confidence 计算

### 为什么先做它

因为它可以非常快地提高训练稳定性，而不需要你马上实现复杂的 clip-level consistency。

---

## 第 5 步：补三阶段训练调度

这个投入很小，但很值。

### 目标

不要直接 hybrid scene 开训。
而是：

#### Stage 1：real-only warmup

* 只用真实 sparse views
* 目的：先稳住几何

#### Stage 2：real + pseudo low-weight

* 引入 pseudo-views
* `alpha_pseudo` 很小，比如 0.1~0.2

#### Stage 3：full hybrid

* 增大 pseudo-view 占比
* 启用 confidence map / consistency down-weight

### 伪代码

```python
if step < warmup_steps:
    use_real = True
    use_pseudo = False
elif step < hybrid_steps:
    use_real = True
    use_pseudo = True
    pseudo_global_weight = 0.2
else:
    use_real = True
    use_pseudo = True
    pseudo_global_weight = 0.5
```

### 为什么这是 P0

因为这是最便宜、最稳的稳定器。
你不需要等 `C_feat`、online update 都做好，先把训练 schedule 改掉就能减少 geometry drift。

# 三、P1：第二批要做的东西

## 第 6 步：补 `C_reproj`

这是 confidence 里最值得先补的第二层。

### 目标

让置信度不只看“可见”，还看“和真实观测对不对得上”。

### 最简单实现

对每个 pseudo-view 像素：

1. 用 refined pose + depth 回投到最近真实 anchor frame
2. 在真实图上采样颜色或 feature
3. 差异小 → 高权重
4. 差异大 → 低权重

### 伪代码

```python
def build_c_reproj(pseudo_img, pseudo_depth, pseudo_pose, anchor_img, anchor_pose, K):
    warped_anchor = reproject_image(anchor_img, anchor_pose, pseudo_pose, pseudo_depth, K)
    err = mean_channel(abs(pseudo_img - warped_anchor))
    c_reproj = exp(-err / sigma)
    return c_reproj
```

### 建议

第一版直接用 RGB error。
后面再升级成 feature error。

---

## 第 7 步：补 masked LPIPS / perceptual loss

这是 OVIE 启发里最容易写进论文、也最容易补的一个点。OVIE 明确把 masked reconstruction 和 masked perceptual 都限制在 valid regions。

### 目标

不要只有 `L1 + SSIM`。
至少给 pseudo-view 分支加一个 masked LPIPS。

### 伪代码

```python
def masked_lpips(pred, target, mask, lpips_net):
    pred_m = pred * mask
    tgt_m  = target * mask
    return lpips_net(pred_m, tgt_m).mean()
```

### 训练损失建议

```python
L_pseudo = (
    w_l1   * masked_l1(pred, target, C) +
    w_ssim * masked_ssim(pred, target, C) +
    w_lpips* masked_lpips(pred, target, C, lpips_net)
)
```

### 为什么它是 P1

不是绝对阻塞，但它能明显让你的 confidence fusion 更像“真正参考 OVIE”，报告也更好写。

## 第 8 步：补 confidence online update

你现在是离线只算一次。
推荐做轻量版在线更新。

### 最轻实现

不要全量重算全部 pseudo-view。
改成：

* 每隔 `N` 个 iter
* 只对当前 batch 用到的 pseudo-views
* 重新渲染 coarse result
* 更新 `C_vis`、`C_reproj`

### 伪代码

```python
if step % update_interval == 0:
    for view_id in current_batch_pseudo_ids:
        coarse = renderer.render(pose[view_id])
        c_vis = build_c_vis(...)
        c_reproj = build_c_reproj(...)

```

### 为什么先做轻量版

因为全量在线更新太贵。
按 batch 重算已经足够写成“online confidence refresh”。

## 第 9 步：补更强评测指标

GLD 很明确地用 ATE、RPE、reprojection error、MEt3R 看几何一致性，而不只看 PSNR/SSIM/LPIPS。

### 你最值得补的顺序

1. **reprojection error**
2. **ATE / RPE**
3. **MEt3R**（最晚）

### 为什么这个顺序最好

* reprojection error：你前面已经在实现链里用到了，最容易复用
* ATE / RPE：如果有 GT pose 或可对齐 pose，报告价值很高
* MEt3R：更重，可以最后再做

# 四、P2：第三批再做的东西

## 第 10 步：补 `C_feat`

这是好东西，但不是最先该做。

### 推荐最小版本

不要一上来接 VGGT。
先用 **DINOv2 / DINO small** 中层特征做 correspondence。

### 做法

* 对 pseudo-view 和最近 real view 提取 dense features
* 用光流或重投影坐标对齐后比较 cosine similarity
* similarity 高 → 高权重

### 伪代码

```python
def build_c_feat(pseudo_img, real_img, warp_coords, feat_net):
    f1 = feat_net(pseudo_img)
    f2 = feat_net(real_img)
    f2_warp = grid_sample(f2, warp_coords)
    sim = cosine_similarity(f1, f2_warp)
    c_feat = clamp((sim + 1) / 2, 0, 1)
    return c_feat
```

### 为什么不是 P0

因为你前面用 `C_vis + C_reproj + C_temp` 已经能把方法做成立。
`C_feat` 是锦上添花，不是最先的命门。

---

## 第 11 步：clip-level consistency

这个更像“高级版 consistency-aware optimization”。

### 目标

不把 pseudo-view 当独立图，而把一整个 clip 作为一个局部 multi-view set。

### 最小实现

先别做复杂的联合优化，先做 **clip-level score**：

[
S_{clip} = \text{mean}(S_{flow} + S_{reproj} + S_{pose})
]

### 使用方式

* clip 分数低：整 clip 降低采样概率
* clip 分数中等：保留，但低权重
* clip 分数高：正常训练

### 伪代码

```python
def score_clip(frames, poses):
    flow_score   = mean_pairwise_flow_consistency(frames)
    reproj_score = mean_pairwise_reprojection_error(frames, poses)
    pose_score   = mean_pose_smoothness(poses)
    return 0.4 * flow_score + 0.4 * reproj_score + 0.2 * pose_score
```

## 第 12 步：patch pruning

这个比 pixel-level 更稳，也更省。

### 最小实现

* 把 confidence map 分成 16×16 patch
* 每个 patch 求均值
* 低于阈值的 patch：

  * 直接 mask 掉
  * 或者衰减到 0.1

### 伪代码

```python
def patch_prune(conf_map, patch=16, tau=0.3):
    patch_score = avg_pool(conf_map, kernel_size=patch, stride=patch)
    keep = (patch_score > tau).float()
    keep = upsample_nearest(keep, conf_map.shape[-2:])
    return conf_map * keep
```

### 为什么放 P2

因为 pixel-level 先做就够用了。
patch pruning 更像稳定化增强项。

## 第 13 步：DynamiCrafter 的“内部几何条件约束”

这是你列出来的缺项里，**最不该先硬补** 的一个。

### 我的建议

先不要改 DynamiCrafter 模型内部。
优先做 **外部 geometry-aware guidance / reranking**。

### 原因

内部改模型意味着：

* 改输入通道
* 改网络 forward
* 重新适配 checkpoint
* 很容易把整个生成链搞挂

### 更现实的替代方案

#### 方案 A：多候选 + geometry-aware reranking

* 每个 pair 生成 K 个候选 clip
* 用 coarse render / reprojection / flow score 打分
* 只保留最符合几何的那一个

#### 方案 B：coarse-render aware filtering

* 生成后与 coarse RGB 做比较
* 偏差大的 clip 直接剔除

#### 方案 C：作为额外图像条件拼接

如果你真的想轻改：

* 把 coarse render 当作辅助图，与 start/end image 拼成三联图
* 只在 adapter 层改输入组织
* 不改 DynamiCrafter backbone

### 为什么这才合理

项目书允许你按自己的最优工程路线实现，只要核心任务满足即可。
所以没必要为“看起来更像论文”去优先做最难改的一块。
